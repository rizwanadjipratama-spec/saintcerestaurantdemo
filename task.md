# Saintce Restaurant - Production-Level Demo Website

## 🎯 Project Overview
Build a premium, clean, and fast modern cafe demo website for "Saintce Restaurant" using Next.js.

## ⚙️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS + Framer Motion (for animations)
- **Icons**: Lucide React
- **Fonts**: Cormorant Garamond (Serif), Inter (Sans)
- **Images**: Next/Image + Unsplash

## 🎨 Design System
- **Coffee Brown**: `#3E2C23`
- **Cream**: `#F5E9DA`
- **Soft Green**: `#7A9E7E`
- **Accent Warm**: `#C97B63`
